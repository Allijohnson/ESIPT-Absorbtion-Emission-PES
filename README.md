# ESIPT-Absorbtion-Emission-PES
Repo with a variety of scripts to aid in an investigative study of potential ESIPT molecules: Generate submission files,  summarize gaussian output files, make graph of PES and .xyz file to visualize proton transfer. Will work best if you copy it. It is also convienient to change the base files to fit the specific parameters you might want (i.e. change the basis set, functional, specific printing parameters, CPU/mem allocations, job naming scheme). For SBATCH specifications documentation: https://slurm.schedmd.com/sbatch.html

# List of packages needed:
os, re, sys, argparse, matplotlib.pyplot, matplotlib.ticker, cclib

# Using files:
I am working on making these a little more user-friendly; most of the scripts were written on an as-needed basis without much thought given to who else might be using the files in the future :/ oops. As a result, it is a little bit clunky to use, but it allows you to organize your files however you would like.

## Generating Submission files:
It is my recommendation that you store the .txt files (AS PLAIN TEXT) in a folder somewhere on your system; then you can input your file path directly. It is important to remember you must change the starting geometry in the Step1 file for Gas and PCM calculations before running, and make sure you know the correct atom index for the proton transfer (turn on Avogadro labels). Edit the molecule_name, solvents, and conformations lists with the values you are interested in. If different molecules have different proton indices, make sure to run them separately and just edit the molecule_name list. It should also be noted that step2c/4c are intended to optimize the proton transfer, so the lowest-energy geometry from the PES scan should be used as the starting geometry, and the file should be edited before submission. The script is set up to generate a desktop folder that contains all of the slurm scripts organized by Gas/PCM and solvent. If running scripts on an HPC, the command: 

scp -r ~/path/to/slurm/script
hpclogin:/path/to/directory

ex: scp -r ~/Desktop/Slurm_script/PCM/imides/HOH/solvent
jsmith@hpc.school.edu:/home/webmo/webmo/jsmith/imides/HOH

Will automatically copy all of the submission files as .sh/.slurm files into a new directory in HOH called the solvent name. This should allow you to navigate to the directory and use sbatch submitAll.sh/submitESIPT.sh to queue all of the scripts with the necessary dependencies. 

The submission scripts include a Python segment that, upon completion of the Gaussian calculation, generates a summary file of the most relevant data. Can be stored on the HPC or copied back to local computer with: 
scp 'hpclogin:/path/to/directory/on/hpc/<filename>.txt' ~/path/to/local/storage
You can replace .txt with whatever file type you want to copy back (ex: .chk, .out)

## Making PES scan Graphs and Visualizations
The pes_plot.py, the pes_plot.py is compatible with both PCM and gas-phase scan outputs with the submission files generated with the script in this repo, but more generally can be run on TD-DFT scans run with Opt=ModRedundant. It pulls the energy and bond length from the last (converged) geometry of each "step" in the scan, and makes a plot of bond length vs energy, which allows you to see the activation energy of a proton transfer. It includes options: --save, which will auto-save as pes_scan.png; --save nameplot.png which will save with a specific name; --coord R(3,4), which will override the coordinate label; --title "Graph title"; and --no-plot if you only want the table generated and not the graph too. Example usage:

python3 ~/path/to/pes_plot.py ~/path/to/output/file/<filename>.out --save molculenameSolvent.png --title "Molecule in Solvent PES Scan" 

The extract_pes.py helps generate an .xyz file that stores all of the geometries in the scan. You can open the file in an app like Avogadro/Spartan to see a visual of the proton transfer. I used this and the PES scan table generated by pes_plot.py to find the lowest-energy geometry after the PES scan and then use it as the starting geometry for the vertical emission calculation (step2c/step4c). Example usage:

cd ~/Desktop #or other filepath
python3 extract_pes.py ~/path/to/output/file/<filename>.out OHBrimhy.xyz


## Cleaning Random Output Files
There is a file with a bunch of methods that can clean an output file and extract data if, for some reason, the Python segment in the submission file failed. These are easiest to run in VS Code, PyCharm, etc. directly. Just change the file paths to go to the output file of interest and put in the solvent if using PCM, using the main method. The output file just has to be the same type of calculation as the cleaning method to work, i.e., ground-state optimization/frequency calc goes with printStep1().
